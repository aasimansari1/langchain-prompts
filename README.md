## 📚 Topics Covered

| Template Type | Description |
|---|---|
| `PromptTemplate` | Basic string templates with variables |
| `ChatPromptTemplate` | Multi-turn conversation templates |
| `FewShotPromptTemplate` | In-context learning examples |
| `OutputParsers` | Structured JSON/list outputs |
| `Chain Prompts` | Chaining multiple prompts |

## 🚀 Setup

```bash
pip install langchain openai python-dotenv
# Add OPENAI_API_KEY to .env
python prompts.py
```
